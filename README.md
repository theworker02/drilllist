# drilllist

Drill encode/decode helpers for list payloads in pipelines.

**Site:** https://theworker02.github.io/drilllist/

## Install / run

```bash
git clone https://github.com/theworker02/drilllist.git
cd drilllist
node src/cli.js
node --test
```
